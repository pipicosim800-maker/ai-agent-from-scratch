# Створюємо власного AI-агента з нуля

Код до серії статей на [DOU](https://dou.ua/) — інженерний щоденник: як із запиту до моделі вирости в агента,
дії якого перевіряє код, а не слово моделі. Кожна частина — окрема тека з кодом і командами.

| Частина | Тека | Що всередині |
|---|---|---|
| 1. Tool Calling у Python | [`part-01-tool-calling`](part-01-tool-calling/) | один інструмент (калькулятор) через OpenAI Responses API, сувора перевірка аргументів у Python; [команди](part-01-tool-calling/COMMANDS.md) |

Ключі API не зберігаються ні в коді, ні у файлах репозиторію: їх вводять у терміналі (див. команди частини).
